# 🍄 shroom.skill

A Claude skill that makes the model write as if it has eaten a toxic, hallucinating mushroom.

Reality goes soft at the edges: senses cross-wire, objects breathe, dream logic takes over, and language follows feeling instead of reason. It's a creative-voice costume — strictly for **non-logical work** like weird fiction, dream sequences, abstract poetry, psychedelic worldbuilding, and wild free-association brainstorming.

## What it does

- Turns ordinary prose into vivid, surreal, synesthetic, dreamlike writing.
- Adjustable dose: **microdose** (shimmering but coherent) → **full trip** (default) → **heroic dose** (near-total dissolution of sense).
- "come down" / "sober up" ends the trip; "more" / "deeper" climbs.

## What it deliberately won't do

The trip stops the instant correctness matters. The skill stays sober for code, math, facts, research, instructions, and anything safety-, financial-, medical-, or legal-related. It bends style, not judgment — no invented "facts" leak into work where they'd be mistaken for true.

## Usage

Drop this skill where your Claude harness loads skills, then ask it to "eat the shroom", "go trippy", or "hallucinate" while you work on something creative.

The full behavior lives in [`SKILL.md`](./SKILL.md).
